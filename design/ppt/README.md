## 돌리는 법

```bash
cd design/ppt
npm install pptxgenjs          # 처음 한 번
node gen_slides.js             # → new-slides.pptx (11장)
PYTHONIOENCODING=utf-8 python graft.py --base "D:/멘타 AI/Space Syntax 상권분석 MVP 소개 (레드 버전).pptx"
```

`build/out.pptx`가 완성본이다. `--out`으로 저장 위치를 바꿀 수 있다.

윈도우 콘솔이 cp949라 `PYTHONIOENCODING=utf-8`을 빼면 진행 메시지를 찍다가 죽는다.

## 검증 (권장)

```bash
python <pptx-skill>/scripts/office/validate.py build/out.pptx --original "<원본>"
```

PowerPoint가 있으면 COM으로 특정 슬라이드만 그림으로 뽑아 눈으로 확인한다 —
한글은 줄바꿈이 단어 중간에서 깨지는 일이 잦아 렌더링 확인이 필요하다.

## 고칠 때

슬라이드 내용은 `gen_slides.js` 안에 슬라이드별 블록으로 나뉘어 있다. 순서·번호를
바꾸려면 `graft.py`의 `order` / `renum` 두 줄을 함께 고쳐야 한다 — 한쪽만 고치면
페이지 번호가 어긋난다.
