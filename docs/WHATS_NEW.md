## 화면 쪽에서 고친 것

밤새 고친 것 대부분이 한 유형이었다 — **엔진 계산은 맞는데 화면이 그걸 반대로
말하거나, 없는 값을 말하거나, 못 믿을 값을 점수에 넣던 자리.**

가장 무거웠던 것:

- **경쟁 0곳이 만점으로 채점되던 버그**. 보행 도로망이 끊긴 지점에서 도달권이
  좁게 잡혀 동일업종이 0곳으로 나왔는데, 그 0곳이 그대로 "경쟁 없음 = 만점"으로
  총점에 들어갔다. 구로디지털단지역에서 실제로 **0곳 → 74곳**으로 잡혔다.
- **비교표가 경쟁 칸에서 가장 경쟁 심한 후보에 "항목 최고"를 달던 것.**
- **입지진단 "핵심 근거" 1위가 어디서든 경쟁 밀도였던 것.** 서울 주요 상권
  다섯 곳을 재 보니 전부 "핵심 근거: 경쟁 밀도 100점 · 매우 높음"이었다.
- **상담 카드가 지어낸 점수·임대료를 분석 결과처럼 적던 것.** 점수는 목록
  순번에서, 임대료는 하드코딩 문자열에서 나왔다.
- **권역·추이 화면이 경고를 계산해 놓고 안 보여 주던 것.**

## 자율 러너

`space-syntax-agent`(Railway)가 사람 없이 개발을 이어간다.

```
정찰 에이전트  →  할 일을 찾아 backlog에 담음 (읽기만, 코드 못 고침)
      ↓
작업 에이전트 2명 동시  →  각자 별도 worktree에서 코드 작성
      ↓
검증(pytest + 프론트 typecheck·test·lint) → 통과분만 push = 배포
      ↓
할 일 떨어지면 다시 정찰로
```

  안전망이다. 실패하면 되돌리고 `FAILURES.md`에 사유를 적는다.
- 구독 토큰으로 인증한다. **API 추가 과금 없음.** 한도에 걸리면 알리고 기다린다.
