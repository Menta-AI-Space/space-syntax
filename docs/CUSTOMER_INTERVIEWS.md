# 고객·실무자 인터뷰 기록

`SPEC_SPACE_ANALYSIS_MODULES.md` §「MVP 골격」 D(3~8주 「고객 인터뷰」)의 기록이다.
**사람·회사 이름은 적지 않는다** — 저장소가 여러 랩탑과 공유된다. 소속은 업종 수준까지만.

각 인터뷰는 ① 들은 것 ② 우리 제품에 주는 뜻 ③ 다음에 물을 것 순서로 적는다.

## 1. 민간 시공사 관리팀 (연구실 동문) — 2026-10 서면 회신

**소속·관점**: LH가 아닌 민간 시공사, 사업수주팀이 아니라 **관리팀** 입장. 예로 든 사업은
목동 재건축처럼 **주거 단지 시공 입찰**이다 — 우리 주력(상업 입지·토지)과 다르다는 점을
감안해서 읽는다.

### 들은 것

1. **단일 지표로 결정하지 않는다.** 지하철 노선, 필지 모양, 기존 용적률, 학군,
   **용적률 인센티브**가 얽혀 사업성이 정해진다. 도로 연결망이 좋아도 인센티브가 낮거나
   학군이 약하면 밀린다 → 통합도·선택도가 사업성과 일치하지 않는다.
2. **결정 과정은 2단계다.** 권역별 조사(상시) → 유망 권역 안 단지별 세부조사(**외부 용역**
   발주 → 1차 결과 → 내부 재검토) → 투자심의(**평균 2개월**) → 입찰 여부.
   외부 용역 내용: 탁상감정, 교통망, **랜드마크성(주요 간선도로·하천변에서 보이는가)**,
   평면 검토, 생활권 상권 분석.
3. **입지 선정 단계에서 하는 것**: 상권분석, 인프라분석, 사업성 분석(법규·견적).
   감정평가·교통영향평가는 **사업 시행 단계**에서 한다.
   **길 구조·접근성은 수치화하지 않고 도로 위계·접근 동선을 정성적으로 평가한다.**

### 우리 제품에 주는 뜻

| 들은 것 | 뜻 |
| --- | --- |
| 단일 지표로 결정 안 함 | 「통합도 = 답」으로 팔지 않는다. **판단 재료 중 한 칸**. 9/30 필지 등급의 결론(맨 위 한 칸만 갈린다)과도 맞는다 |
| 2단계 + 외부 용역 | 들어갈 문이 둘이다 — **권역 조사**(내부 팀, 빠른 1차 거르기, 5초 룰이 강점) / **세부조사 용역사**(보고서에 붙일 근거 그림·수치). 돈을 내는 쪽이 **용역사**일 수 있다 → 인터뷰 대상을 용역사로 넓힌다 |
| 정성 평가 | 우리가 메울 빈칸. 문구 후보: "보고서의 '접근성 양호' 한 줄을 근거 있는 지도·수치로" |
| 랜드마크 = 간선도로·하천에서 보이는가 | **새 기능 후보: 실외 가시성**. 지금 VGA는 실내 도면에만 쓴다(`floorplan_vga.py`). 간선도로·하천에서 대상지가 얼마나 보이는지(아이소비스트)는 아무도 수치화하지 않은 영역 — 아직 설계·결정 전 |
| 감정평가·교통영향평가는 나중 | 우리는 그 앞 **입지 선정 단계**. 감정평가와 겹치지 않는다 → 「감정평가 아님」 원칙과 맞는다 |

⚠️ 주거 재건축 관점이라 학군·용적률 비중이 크다. **"길 구조는 쓸모없다"로 읽지 않는다.**

### 다음에 물을 것

1. 외부 용역 보고서 **목차**, 비용·기간, 주로 맡는 업체 유형
2. 권역 조사 때 보는 **지표 목록**과 쓰는 도구
3. 단지 내 상가·상업시설은 누가 어떻게 검토하나 (상권 모듈이 직접 닿는 곳)
4. "간선도로에서 보이는 자리"를 지금 어떻게 판단하나 (현장 답사·사진)

## 2. 도시계획 인허가 실무자 — 질문 준비 (2026-10-11, 아직 안 만남)

**⚠️ 공개 전 계획·내부 정보는 묻지 않는다** — 상대가 법적으로 곤란해지고 서비스도 문제가
된다. 공개 자료의 위치와 절차까지만 묻는다.

먼저 확인: 지자체 공무원인가, 인허가 대행(엔지니어링·건축사무소)인가.
