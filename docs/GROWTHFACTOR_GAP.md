## GrowthFactor가 파는 것 (사이트 실조사)

한 문장으로: **"당신의 최고 애널리스트에게 물어보듯 물으면, 도구를 돌리는 과정을
보여주며 방어 가능한 답을 준다."** 구성은 셋:

| 축 | 내용 |
|---|---|
| PLAN (Market Planning) | "다음에 어디 열까" — 시장 전체를 한 대화로 계획, 후보 순위 |
| EVALUATE (AI Site Scoring) | 주소 점수화 — 자기 포트폴리오의 비슷한 매장(analogs)과 대조 |
| DECIDE (Deal Management) | 딜 파이프라인(칸반: Searched→Review→LOI), 메모 자동 작성 |

핵심 UX 패턴:
1. **대화가 기본 화면.** 질문 → 도구 호출이 이름과 함께 순서대로 표시
   (`score_location ×2 DONE`, `run_model DONE`, `get_cannibalization DONE`) → 판정.
2. **후속 질문이 자연스럽다.** "What's holding Orlando back?" → 이유 심층 답변.
3. **모든 숫자가 출처로 추적된다** (TRACED TO SOURCE): 예측 매출 ÷ 면적 = $/sqft,
   각 값에 범위(range) 병기. "점수만 주고 계산을 숨기는 도구"를 정면 공격.
4. **5개 렌즈 점수 + 가중치를 사용자가 조정** (demographics/foot traffic/
   competition/visibility/market potential).
5. **MCP 제공** — Claude·ChatGPT·Cursor가 그들의 스코어링 엔진을 직접 도구로 씀.
6. Labs: 고객 매출 데이터로 맞춤 예측 모델 (전담 데이터 사이언티스트).
