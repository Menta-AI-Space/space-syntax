# 커리어 블로그 기획 — 하루 15분으로 주 1편 (2026-10-30)

운정신도시·계획도면·평면도 분석을 온라인에 올려 **내 커리어(공간 분석 + AI 제품을 만드는 사람)를 보여 주는 곳**을 만든다.
10/13 「운정 중앙역 분석 결과 공유 전략」(카페로 의뢰 수요 떠보기, `WORKLOG_상업용입지분석AI.md`)을 이어받되, 목적을
**커리어 포트폴리오**로 넓혔다.

- 브런치 — 작가 심사가 있어 시작이 늦다.

## 3. 올리지 않는 것 (지켜야 할 선)

- **가격·오를지·사라/입찰하라**는 말. 「구조가 이렇다」까지만. 글 끝에 「가격·투자 판단은 이 분석이 말해 주지 않습니다」 한 줄 (`CLAUDE.md` §4, §26).
- 「싸다·저평가」 표현.
- 쇼핑몰 **실명**, 고객·실무자 인터뷰 내용(`CUSTOMER_INTERVIEWS.md`는 비공개), 회사·사람 이름.
- LH 공고 첨부 원본 파일 — 다시 올리지 말고 공고 번호·링크만.
- 학번·연락처 등 개인정보. 의뢰 연락은 블로그 쪽지·안내 메일 하나로.

## 4. 글 한 편의 틀 (짧게, 5칸)

1. **제목** — 「운정중앙역 F10, 길 구조로 보면」처럼 장소 + 질문.
2. **한 줄 답** — 맨 위에 결론 한 줄 (바쁜 사람은 여기까지만 읽는다).
3. **그림 1~3장** — 라이브 사이트 캡처. 그림마다 한 줄 설명.
4. **어떻게 했나** — 3~5줄. 데이터 출처, 사용한 방법.
5. **이 분석이 말해 주지 않는 것** + 「직접 눌러 보기」 링크.

분량은 1,000~1,500자. 길게 쓰려다 멈추는 것보다 짧게 매주 나가는 게 낫다.

## 5. 올리는 법 (처음 한 번)

1. 네이버 블로그 → 「블로그 관리」에서 이름·소개를 정한다. 예: 블로그 이름 「목좋은곳 연구노트」, 소개 「길 구조와 도면으로 상권을 읽습니다. 공간 분석 × AI」.
2. 카테고리 다섯 개: `운정·신도시` / `건축 평면도` / `서울 길 지도` / `만드는 과정` / `공부 노트`.
3. **첫 글은 「소개」 글**(초안 `docs/blog/00_소개.md`)로 쓰고 「공지」로 고정한다 — 나는 누구, 무엇을 만드는지, 라이브 사이트 링크, 글 목록. 링크드인·이력서엔 이 글 주소만 건다.
4. 글 쓰기: 휴대폰 네이버 블로그 앱 「글쓰기」 → 「임시저장」을 하루하루 이어 쓴다. 발행 전 PC에서 그림 크기만 확인.
5. 태그 5개 안팎: `#운정신도시 #LH상가용지 #공간구문론 #상권분석 #도시계획`.
6. 예약 발행: 매주 같은 요일·시간(예: 토 오전 9시) — 독자가 리듬을 알게 된다.

**바쁜 날 5분 버전**: 그날 칸을 못 하면 휴대폰 메모에 「이번 글에 넣을 문장 하나」만 적는다. 0분인 날보다 낫다.
**밀리면**: 그 주는 글을 반으로 줄여 금요일에 낸다. 한 주 쉬는 것보다 짧은 글이 낫다.

Claude에게 맡길 수 있는 것: 「이번 주 ⑤번 글 초안」이라고 하면 문서·작업 기록에서 숫자를 꺼내 5칸 틀로 초안을 쓴다. 그럼 월~목 칸이 「읽고 고치기」로 줄어든다.
